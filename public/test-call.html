📞 Test Call — talk to Charco

This is exactly how a phone call with the assistant flows: Charco greets you, asks your name, understands your question or takes your message — and saves a summary for Miller. Use Chrome or Edge on your phone or laptop, and allow microphone access.

Short calls by design: Charco keeps every call under 1 minute — normally it wraps up in 20–30 seconds. The timer above shows the live duration; at 45 seconds Charco politely wraps up, and the call ends at 60 seconds at the latest.
Demo mode: this call runs 100% in your browser using the Web Speech API — free, no account needed. Real phone calls (on Miller's actual number) activate after the Twilio telephony keys are added to the server's .env file. Mic works on localhost or HTTPS pages.
Two ways to call: use the toggle below — Answering mode is what any caller experiences; Command mode is what happens when Miller himself calls the number: Charco recognises him, takes a spoken command, and saves it to the Command inbox.

🗂️ Command inbox

Commands dictated in Command mode land here with status New — the demo keeps them in this browser (localStorage), just like the server keeps real ones for GET /api/commands. On real calls, Charco picks up each New command, executes it, reports back on WhatsApp, and marks it Done.
