How it works

  1. Calls run through Twilio webhooks (/voice/incoming, /voice/gather, /voice/outbound).
  2. A built-in dialogue manager matches questions to FAQs and captures names and messages — no paid AI key required.
  3. Summaries are stored in data/calls.json and readable at /api/calls.
  4. Real phone calls activate the moment Miller adds his own Twilio keys to .env — see the README for the exact steps.
